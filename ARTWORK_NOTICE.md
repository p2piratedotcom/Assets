# Coin artwork provenance

The 453 PNG files in `icons/` are restored from the previously used
`coin_icons/png/` set. They match the files in
[`ShorelineCrypto/coins@98b29f5`](https://github.com/ShorelineCrypto/coins/tree/98b29f5ea53a46a701e791a565a5fab7ee83b947/icons).
The project owner has stated that they have authorization to use these PNGs.
No license or permission document for the artwork has been supplied for
publication here. The Unlicense in this repository does not apply to the PNGs;
their inclusion should not be treated as a general permission to reuse them.
